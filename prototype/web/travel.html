解析出城市 / 天数 / 兴趣后自动填充并预选景点；未配 AI 时支持「城市 + 天数」极简格式。

② 怎么过去？

城际时间/票价按距离估算（车次票价以 12306 / 航司为准）；上车站与接驳时长来自内置车站表 + 路网估算，接入真实票务 API 后替换。

⑤ 地图导航（雏形）

右侧地图已画出整条路线：绿色虚线=步行、橙色虚线=骑行、蓝色=公交地铁、紫色=打车，数字圆点为游玩顺序，🏨 为住宿/出发点。点任意一段线可查看该段并跳转导航。
