② 怎么过去？

🛫 出发城市 · 上车站 / 机场
🛬 目的城市 · 下车站 / 机场

火车站来自 12306 免费车站库（本机缓存 7 天），机场优先用内置数据；只有内置没有的站点才会请求百度，且结果会缓存。搜索后可选任意车站 / 机场，接驳里程按所选站点重算。

城际时间/票价按距离估算（车次票价以 12306 / 航司为准）；上车站与接驳时长来自车站库 + 路网估算，接入真实票务 API 后替换。

⑤ 地图导航（雏形）

右侧地图已画出整条路线：不同颜色 = 不同天数，线型区分方式（点线=步行、长虚线=骑行、实线=公交地铁、疏虚线=打车），同一天颜色相同、多天自动换色，避免线路叠在一起看不清。数字圆点为游玩顺序，🏨 为住宿/出发点。点任意一段线可查看该段并跳转导航。

开启后「攻略问答」和「AI 生成攻略」会先联网检索再作答，回答下方附可点击来源；讲解仍严格基于行程数据（不引入外部事实）。DeepSeek 官方搜索按成功请求计费（$0.75 / 千次），相同问题 6 小时内命中本地缓存、不重复计费。

高级：按能力分流（可选）

默认「自动」：路线先走百度、地点先走高德，两家额度各摊一半。任一项指定后，地图工具栏的路网按钮会显示「自定义」。

本地持久缓存

地点与路线结果会保存到本机；超出上限时按使用频率自动清理低频条目。

推荐：OpenRouter 免费模型（浏览器直连，无需本地服务）；现场断网时用「离线演示」通道。两类 key 永远不会写进代码仓库。
